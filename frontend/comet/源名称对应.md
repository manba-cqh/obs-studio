# OBS Studio 源类型 ID 与中文名称对照表

本文档列出了 OBS Studio 中常见源类型的中文名称和对应的 source ID。

## 基础类型

| 中文名称 | Source ID | 说明 |
|---------|-----------|------|
| 场景 | `scene` | 场景容器 |
| 分组 | `group` | 源分组容器 |

## 图像和颜色源

| 中文名称 | Source ID | 说明 |
|---------|-----------|------|
| 图像源 | `image_source` | 显示静态图片 |
| 颜色源 | `color_source` | 纯色背景 |
| 幻灯片放映 | `slideshow` | 图片轮播 |

## 文本源

| 中文名称 | Source ID | 说明 |
|---------|-----------|------|
| 文本（FreeType 2） | `text_ft2_source` | 使用 FreeType2 渲染的文本 |
| 文本（GDI+） | `text_gdiplus` | Windows 平台使用 GDI+ 渲染的文本 |

|---------|-----------|------|

## 使用说明

在代码中，可以通过以下方式获取源类型：

```cpp
obs_source_t *source = ...;  // 获取源对象
const char *sourceId = obs_source_get_id(source);  // 获取源类型 ID
```

然后可以根据 source ID 来显示对应的图标或执行相应的操作。

## 注意事项

1. 某些源类型可能有版本后缀（如 `_v1`, `_v2`），实际使用时需要去掉版本号进行匹配
2. 不同平台可能有不同的源类型可用
3. 第三方插件可能会注册额外的源类型
